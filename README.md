# TON Address Suffix Generator

Простой CLI-инструмент на Go для подбора TON-кошелька с нужным суффиксом адреса.

## Что делает

- Спрашивает желаемые последние символы адреса.
- Определяет доступное количество потоков через ОС (переменная `NUMBER_OF_PROCESSORS`) с fallback на `runtime.NumCPU()`.
- Позволяет выбрать, сколько потоков использовать.
- Перебирает seed-фразы и ищет точное совпадение по суффиксу.
- Если точного совпадения нет, хранит и выводит самый близкий вариант.

## Как запустить

### Вариант 1: из исходников

```bash
go run .
```

### Вариант 2: собрать бинарник

```bash
go build -o ton-generator.exe .
./ton-generator.exe
```

## Как работает выбор потоков

После ввода суффикса программа показывает:

- сколько потоков доступно на компьютере;
- запрос, сколько потоков использовать (`1..N`, где `N` — доступное число).

Правила:

- Enter без ввода -> используется максимум (`N`);
- число меньше `1` -> ставится `1`;
- число больше `N` -> ограничивается до `N`;
- некорректный ввод -> используется значение по умолчанию.

## Почему лучше использовать эту программу, а не сайты

Локальная утилита обычно лучше онлайн-сервисов для такой задачи:

- Безопаснее для seed-фразы: генерация идет на твоем ПК, а не на чужом сервере.
- Меньше риска утечки: ты не вставляешь чувствительные данные в форму на сайте.
- Контроль нагрузки: можно самому выбрать число потоков и не убивать систему.
- Предсказуемость: нет лимитов, рекламы, капч и внезапных ограничений по времени.

Если коротко: локальный запуск дает больше контроля, приватности и стабильности.

## Важно

- Seed-фраза — секрет. Не храните ее в публичных логах и не отправляйте третьим лицам.
- При большом количестве потоков нагрузка на CPU будет высокой.
